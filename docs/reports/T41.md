# T41 汇报：阶段目标

**结论**：✅ 完成。菜单里多了"目标"，14 个里程碑，每个第一次达成时发一次奖金和声望。没有结局。

**做了什么**
- 14 个目标（`src/data/goals.json`，都能改）：
  - 起步：第一场胜利、打进季后赛、第一个冠军、第一个盈利赛季。
  - 养人：培养出能力 80 的明星、赛季 MVP、有人进名人堂。
  - 放手：经理、教练、财务三个岗位都有人。
  - 集团：第二个分部、三个项目都有队伍、分部也夺冠。
  - 远期：MOBA 三冠王朝、同一赛季三个项目全夺冠、声望到 90。
- 奖励从 3 千到 8 万不等，越难的越多，都走账本。
- 达成时收件箱有一条消息，助理会提醒，点"去看看"打开目标窗口。
- 目标窗口：每个目标写着条件、奖励；没达成的有进度条，达成的写哪个赛季达成。
- 进度全部从游戏状态现算。只有三个数需要另外累计：总胜场、盈利赛季数、三冠次数。
