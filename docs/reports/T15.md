# T15 汇报：合同与转会

**结论**：✅ 完成。选手有合同、会到期、能续约，可以和其他俱乐部互相买卖。

**做了什么**
- **合同**：签自由球员时选 1–3 年（界面在 T18，现在默认 2 年）。合同到期又没续约的选手，赛季结束后会成为自由球员。
- **身价**：按能力、年龄、潜力、状态算。年轻、潜力高的人更值钱，过了 27 岁开始掉价。
- **续约**：合同最后一个赛季可以谈。选手按自己的身价和心情开价，你可以接受、拒绝，或还价一次。还价太低他会不高兴，拒绝续约他会更不高兴。
- **违约金**：按剩下的合同算，剩得越多赔得越多（以前固定 3 周工资）。
- **转会（只在休赛期）**：
  - 你可以向 AI 俱乐部报价买人：报价太低会被拒绝，首发比替补贵；AI 只剩 5 个人时不卖。
  - AI 也会向你报价，买你队里比它们首发强的人，报价进收件箱，接受或拒绝都行。
  - 合同跟着人走，转会费一边出一边进。
- **提醒**：赛季开始和季后赛开始时，收件箱会提醒哪些人合同快到期。
- AI 俱乐部目前用简单规则：赛季结束先续约自己付得起的首发；人数不够时，只签自己付得起的自由球员。更完整的 AI 经营在 T17。

**怎么验证的**
- `npm test`：通过 118 / 失败 0（本任务新增 9 个，改了 3 个旧测试来适应合同规则）
- `npm run lint`：0 个问题；`npm run build`：成功
- 浏览器自动操作：从开局打完第 1 赛季、进入第 2 赛季，页面 0 个报错
- 验收逐条：
  - ✅ 资金守恒：买人、卖人前后，所有俱乐部的钱加起来不变
  - ✅ 合同到期的选手正确离队，进入自由市场；如果他在首发里，阵容会清空，提示你重新布阵
  - ✅ AI 不会签超出预算的人：钱不够时宁可缺人也不透支；钱不够的 AI 也不会报价
  - ✅ 同一个 seed 结果相同（报价、合同、市场完全一致）

**需要你知道的**
