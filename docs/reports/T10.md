# T10 汇报：比赛画面

**结论**：✅ 完成。比赛页现在能看到俯视像素小人在地图上跑、打、放技能、推塔；可以暂停、1/2/4 倍速、跳过，看完后进战报结算。

**做了什么**
- `src/render/MatchScene.ts`（Phaser 画面）：
  - 地图：兵路、野区小路、河道、两个中立资源（守望者、晶核）。
  - 单位：塔和基地画成方块加血条；兵团画成三个小方块；英雄是用代码一格一格画出来的 8×8 像素小人，按队伍上色，头顶有选手名和血条。
  - 效果：普通攻击是一闪而过的细线，塔的攻击是橙线；放技能时目标处有黄色光圈；死亡后变透明；击杀、推塔、拿资源、团战会在地图上弹出中文字。
- `src/render/player.ts`（播放控制）：按倍速推进比赛，在两秒之间做插值，让移动更平滑；"跳过"就是不画画面，一直推进到结束。和"看完"用的是同一套推进函数，所以结果不可能不一样。
- 比赛页（`src/ui/pages/Match.tsx`）：顶部比分条（时间、双方击杀、经济差、剩余塔数），右侧事件滚动列表（用俱乐部名字，不写"蓝方/红方"），底部是暂停、1×/2×/4×、跳过按钮。比赛结束后点"查看战报"才结算。
- Phaser 只在进入比赛页时才加载，管理界面打开速度不受影响。

**怎么验证的**
- `npm test`：通过 89 / 失败 0（本任务新增 4 个）
- `npm run lint`：0 个问题；`npm run build`：成功
- 验收逐条：
  - ✅ 同一场比赛"看完"和"跳过"结果完全一致。自动测试会模拟每秒 60 帧观看，中途反复切换倍速、暂停，最后和直接跑出的结果对校验码，完全相同；中途跳过也一样。
  - ✅ 4 倍速画面 60 帧/秒。测的是无显卡的服务器浏览器（纯软件渲染），普通笔记本只会更快。
  - ✅ 1 倍速整场约 2–3 分钟（参数 `realSecPerTickAt1x = 0.115`，24 分钟的比赛约 2 分 45 秒）
  - ✅ 浏览器里完整走通"进入下一周 → 看比赛 → 4 倍速 → 跳过 → 查看战报"，没有报错
