# T32 汇报：待办与审批

**结论**：✅ 完成。负责人超出额度的事会排进"待你拍板"，你点"批准"或"驳回"就行。只有大事才让时间停下，其他的只在顶部显示"待批 N"。每周一收件箱有一条负责人周报。

**做了什么**
- **待你拍板**（负责人窗口最上面）
  - 每条写清：哪个岗位、谁提的、要做什么、为什么、花多少钱或进账多少、几天后作废。
  - 大事左边有红边，标"大事"。
  - "批准""驳回"两个大按钮，手机上一只手能点完。
- **批准**：负责人去办，日志记"已批"。如果现在办不了（比如钱不够），这件事留在列表里，弹一句原因；如果情况已经变了（比如那名选手被别人签走），就从列表里去掉，日志记"过期"。
- **驳回**：日志记"驳回"。如果是卖人，就拒绝那份报价，选手留下。
- **过期**：2 周没处理自动作废，日志记"过期"，写"你没有回复，没做"。换赛季时上赛季没处理的也作废。
- **什么时候停时间**：只有两种大事。
  - 卖"首发最强 N 人"里的选手。
  - 超预算：这笔开销会动用备用金（财务按风格留的那几周开销）。
  - 人数不够 5 人时补人、续约不算超预算，不会被卡住，免得凑不齐人上场。
  - 停下时自动打开负责人窗口，提示"有件大事要你拍板"。
- **顶部按钮**：有待批时，钱旁边出现红色"待批 N"，点一下直接打开负责人窗口。
- **周报**：每周一收件箱一条，例如"本周负责人做了 3 件事，提了 1 条建议，待你批 2 件"。
  - 有待批时，助理会在基地里提醒，点"去看看"打开负责人窗口。
  - 没有待批时只进收件箱，不弹提醒，不烦人。
  - 没雇人、或这周什么事都没有时不发。
  - 收件箱筛选里多了"负责人"一类。
