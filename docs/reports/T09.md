# T09 汇报：管理界面

**结论**：✅ 完成。浏览器里能从开局一路玩到看完战报，再连打 10 轮直到赛季结束。比赛页目前是占位（直接出结果），T10 换成像素画面。

**做了什么**
- 页面：开局页、主页、市场、阵容、赛程与积分榜、财务、战报、设置，外加比赛页占位。
- 顶部资金条常驻：当前资金、按当前开销能撑几周；资金偏低变黄，资金为负变红。
- 市场：按位置筛选，可按能力、工资、性价比排序；直接显示签约费和周薪；右侧是我的队伍，显示还缺哪个位置。
- 阵容：5 个位置卡片，各选选手和英雄（显示熟练度和技能说明）；打副位置、非擅长位置、用不熟练的英雄都有提醒；4 种战术各有一句话说明；有"一键推荐"按钮。
- 战报：一句话结论、3 条关键原因、经济差曲线、双方选手评分和 MVP、本周收支、下一场对手。
- 自动存档：每次操作后都会保存，刷新页面进度不丢。存档坏了会提示，不会白屏，也不会盖掉旧存档。
- 设置：导出存档文件、导入存档文件（导入前先校验，再让你确认）、开始新游戏。

**怎么验证的**
- `npm test`：通过 85 / 失败 0
- `npm run lint`：0 个问题；`npm run build`：成功
- 用浏览器自动操作（Playwright，一种让程序替人点网页的工具）把整条流程跑通，全程没有报错：
  - ✅ 开局 → 签 5 人 → 一键推荐 → 保存阵容 → 进入下一周 → 看战报，约 3.5 秒操作完（真人不看说明大约 3–5 分钟）
  - ✅ 刷新页面后资金、轮次不变
  - ✅ 导出的存档文件能导入恢复
  - ✅ 主存档损坏时自动读取备份并提示；备份也坏了，或者存档版本过新时给出提示，原存档不删除
  - ✅ 连打 10 轮，主页显示"赛季结束、最终排名、资金变化"

**发现并修复**

- 导出存档的文件名有中文时，有些浏览器会把它改成 "download"，所以改成英文文件名，例如 `esports-empire_round3_20261022.json`。
