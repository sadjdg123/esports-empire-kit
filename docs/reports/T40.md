# T40 汇报：分部总监与集团报表

**结论**：✅ 完成。每个分部可以雇一个总监全权代管；报表的"本赛季"里能按分部看收支。

**做了什么**
- **分部总监**（逻辑在 T38 一起做了，界面在 T39 的"总监"标签）：
  - 每个分部每季 3 个候选人，能力 30–95，能力越高周薪越高（150 起，每分加 6）。
  - 两档：我亲自管 / 交给总监，随时切换。解雇付 4 周工资。
  - 交给总监后，他每周补齐阵容、续约、定训练，比赛日排阵；射击还会看对手惯用的打法选克制的打法。
  - 能力低的总监看人有偏差，有时选错打法。
  - 每件事都记下来，写明原因和花费，在分部窗口"总监"里看。
- **报表按分部看**：报表 →"本赛季"多了一张表，MOBA、射击、卡牌各一行：收入、支出、净额。只开了 MOBA 时不显示。
- 说明：分部总监和 P3 的经理、教练、财务是两套。那三个岗位只管 MOBA，分部各自只有一个总监。
