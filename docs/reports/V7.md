# V7 汇报：开罗风格一层可拖拽基地大平层与全界面 UI 升级

## 一句话结论
已将主界面双层小竖楼重构为**开罗式一层三开间可拖拽电竞基地大平层（含户外前庭院）**，并把顶栏、快捷底栏、弹窗、表格、按钮、开局页、比赛日窗口等全部界面升级为正统开罗掌机经营风格，自动测试全部通过。

## 做了什么
1. **一层三开间电竞基地大平层 + 户外前庭院（`src/render/club/ClubScene.ts`）**
   - 告别原本拥挤的上下两层竖楼，改为 `300×200` 像素斜 45° 等轴测一层横向大平层：
     - **左区 · 休息室与直播工坊**：暖木地板、红色大沙发、双人床铺、茶几、自动饮料机、壁挂电视（点开赛程）、2 级落地灯与挂画、3 级动态游鱼水族箱；右侧为直播工坊（环形补光灯、双屏直播桌、闪烁 `LIVE` 灯牌、3 级绿幕）。
     - **中区 · 职业训练大厅与战术分析区**：蓝白棋盘格地板、3 级金边战队地毯、8 台发光电竞训练机与战队电竞椅（点开训练）、后墙巨型战术白板（点开阵容）、战队星标锦旗、采光窗、动态比分大屏、赛事彩旗、2 级战术分析台、3 级全息沙盘桌；屋顶悬浮战队招牌与射击/卡牌分部铭牌（点开集团分部）。
     - **右区 · 行政经理室与荣誉展厅**：绿格地毯、3 级贵宾红毯、战术书架（点开战报）、金银奖杯陈列柜（点开历史）、金库保险柜（点开财务）、总经理办公桌（点开合同转会）、负责人三联办公长桌（点开委任）、2 级饮水机、3 级地球仪。
     - **户外前庭院**：绿茵草地、小花簇、石板步道、迎宾地垫、红顶信箱（点开收件箱）、转会告示牌（点开签人）、红色工具箱（点开设施升级）与景观树。
   - 室内隔断墙改为开罗式半高矮墙，不遮挡后排家具与走动小人；取消上下楼电梯，选手和负责人在贯通走廊里跨房间自由走动串门。
2. **镜头拖拽平移、缩放与房间快捷切镜（`src/ui/components/BaseView.tsx`）**
   - 支持**鼠标按住左右上下拖动**、手机触屏单指滑动平移、滚轮缩放与右上角 `🔍 1.0× / 1.5× / 1.9×` 放大镜切换。
   - 基地顶部提供 `🏠 全景`、`🛋️ 休息直播`、`💻 训练大厅`、`📋 行政荣誉`、`🌳 户外庭院` 快捷镜头按钮，点一下平滑移到对应区域。
   - 新增 `🏷️ 导览` 开关：开启后在画面家具上方浮现开罗风中文小铭牌（有待办事项时带金色叹号闪烁），点击铭牌或家具本体都能直接打开对应功能窗口；底部增加基地实时动态播报条。
3. **全界面开罗风 UI 换装（`Hud.tsx`、`App.tsx`、`MenuGrid.tsx`、`Start.tsx`、`styles.css`）**
   - **顶部木框金边状态栏**：带俱乐部队徽铭牌、下一场比赛倒计时胶囊、带每周净收支提示的金币胶囊、声望星标与立体时钟速度按钮。
   - **底部开罗快捷船坞栏**：常驻 `阵容 / 训练 / 签人 / 合同 / 赛程 / 集团 / 菜单` 7 个高频大图标按钮，有待办时右上角亮红点。
   - **开罗风弹窗、表格、按钮与徽章**：双层木框金钉窗口、暖色条纹数据表、立体按压感按钮、S/A/B/C 金属光泽能力徽章、比赛日红蓝对战横幅（`VS`），以及带实时队徽与队长像素小人预览的开局建队页。

## 怎么看效果
1. 在项目目录下运行：`npm run dev`
2. 浏览器打开终端显示的地址，先看全新的开局建队页（选不同俱乐部能实时看到队徽配色和队长像素小人换装）。
3. 进入主界面后：
   - 点右上角 `🔍 1.5×` 放大基地，按住鼠标左键（或手机手指）左右拖动巡视左中右三个房间和前院；
   - 也可以直接点基地上方的 `🛋️ 休息直播 / 💻 训练大厅 / 📋 行政荣誉 / 🌳 户外庭院` 一键切镜头，或点 `🏷️ 导览` 直接看每个家具的名字标签；
   - 点底部的快捷栏或菜单，查看换装后的各个开罗风窗口、表格和比赛日对战面板。
