# F2 汇报：签人和阵容提醒（GATE-4 试玩反馈）

**门哥的反馈**：第一季全签能力最高的选手，只打了 3 胜 7 负，钱也用光了。

**原因**（看了门哥的存档并重放确认）：
- 签的 5 个人里有两个辅助（Lanternfish、不语），没有射手。
- Lanternfish 被排去打射手，用的还是辅助英雄，伤害位等于空了。
- 用同一个存档种子重放，同样的签法还是 3 胜 7 负。只把"不语"换成射手：
  - 换惊蛰：9 胜 1 负
  - 换逐光：8 胜 2 负
- 游戏数值本身没问题，问题是游戏没拦住"漏掉一个位置"。

**改了三处（只加提醒，不改任何数值）**
1. **签人窗口**：
   - 顶部红框"⚠ 还缺：射手……"。
   - 缺的位置的选手名字后面有绿色"补位"标签。
   - 再签一个已有位置的人、而别的位置还空着时，会先弹窗确认："你还没有射手。不语 是辅助，队里已经有辅助了……确定还要签他吗？"
2. **阵容窗口**：有人打不会的位置时，顶部红框写明"Lanternfish 在打射手，这不是他会的位置，发挥会明显打折。队里没有射手，去签人补一个"，"去签人"可以直接点。
3. **钱**：
   - 签人窗口一直显示"💰 现在这套阵容：赛季中每周预计净亏 ¥X，约 N 周后资金用完"。
   - 每签一个人，提示里也写签完后的情况。
   - 这里是按赛季中的平均情况估的：赞助、联赛分成、周边，加上平均的胜负奖金。连输的话会亏得比这个多。
