# T19 汇报：斜视角俱乐部场景（最简）

**结论**：✅ 完成。主页上能看到自己的俱乐部基地，选手小人会按当天安排在房间之间走动。手机上不卡。

**做了什么**
- 主页新增"俱乐部基地"：45° 斜视角像素小屋，分训练室、休息室、办公室 3 个房间，有电脑桌、沙发、床、书架、绿植，墙上有你俱乐部颜色的海报。
- 选手小人（穿你俱乐部的颜色）按当天情况自己走过去：
  - 正常训练日：在训练室电脑前坐着练
  - 休息周，或疲劳 ≥70：去休息室躺下，头上冒"z"
  - 士气低或状态很差：站着发呆，头上冒"…"
  - 合同快到期还没谈：去办公室，头上冒"!"
  - 办公室桌后面坐着的是你（经理）
- 安排一变，比如切到"休息"，小人会沿走廊走到新房间。
- 画面下面用文字写清楚，比如"训练室：A、B、C 在练操作"。
- 点小人会弹出这名选手的详情卡。场景里不能建造、摆家具或下指令（P2 再说）。
