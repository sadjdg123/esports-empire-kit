# T07 汇报：迷你经营逻辑

**结论**：✅ 完成。经营闭环（纯逻辑，没有界面）已经能完整跑一个 10 轮赛季。

**做了什么**
- `src/game/`：新游戏、自由市场（签约/解约）、阵容（设置 + 一键推荐）、赛程（6 队双循环 10 轮，按种子生成）、每周结算、积分榜、财务。
- 每周结算顺序：扣周薪、发赞助 → 打完本轮 3 场比赛（AI 之间的比赛也真实模拟）→ 发奖金 → 更新积分榜 → 所有选手状态小幅随机变化。
- 按任务书要求拆成两步：`prepareWeek` 先把玩家这场比赛交给画面层播放，`commitWeek` 再结算；不传结果就内部自己跑，结果完全一样。
- 财务：每笔收支都记账；能算出"按当前开销还能撑几周"；资金低于 3 周工资时报警；资金为负时不能签人，但比赛照常进行。
- 新命令 `npm run sim -- --economy`：用"每个位置签性价比最高的选手 + 一键推荐阵容"自动打 100 个赛季，检查经济是否合理。

**怎么验证的**
- `npm test`：通过 73 / 失败 0（本任务新增 13 个）
- `npm run lint`：0 个问题
- 验收逐条：
  - ✅ 资金守恒：起始资金 + 全部收入 − 全部支出 = 当前资金（每周都核对）
  - ✅ 不能超过 8 人；赛季中不能少于 5 人；钱不够签人会说明原因
  - ✅ 同一种子赛程完全相同；每队每轮只打一场，每对对手主客各一次
  - ✅ 10 轮后积分榜：每队 10 场，总共 60 场次、30 场胜利
  - ✅ "先看比赛再结算"与"直接结算"的结果完全一样
  - ✅ 经济校准：100 个赛季，赛季末资金 / 起始资金全部落在 1.17–1.29 之间（标准是至少 80% 落在 0.6–1.5）

**做了哪些决定**（D24）：经济数值调为起始资金 10 万、每周赞助 5000、胜场奖金 8000、负场 2000。
