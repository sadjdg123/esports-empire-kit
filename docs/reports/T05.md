# T05 汇报：胜负、事件日志、战报

**结论**：✅ 完成。一场比赛能完整输出：结果、选手数据、经济曲线、事件日志、校验码和中文战报。

**做了什么**
- `src/sim/engine.ts` 补全对外接口：`createMatch / step / isOver / getSnapshot / finalize / runMatch`。"看比赛"和"跳过"走同一个 `step`。
- `finalize`：统计每名选手的击杀/死亡/助攻、金币、伤害、评分（1–10）、MVP，每 30 秒记一次经济差，并算出校验码（checksum，用来核对两次结果是否完全一样）。
- `getSnapshot`：给画面层用的快照，包括所有单位位置、血量、本秒的攻击和新事件。
- `src/sim/report.ts`：中文战报 = 一句话结论 + 3 条关键原因 + 评分。原因优先挑能对应赛前决定的：战术、招牌英雄熟练度、选手位置、阵容实力。每条原因都挂着对应的事件编号。
- 命令 `npm run sim -- --one --seed 42`：跑一场并打印中文战报和关键事件。可以用 `--blue tianshu --red huiyan` 指定俱乐部。

**怎么验证的**
- `npm test`：通过 59 / 失败 0（本任务新增 8 个）
- `npm run lint`：0 个问题
- 验收逐条：
  - ✅ 同一种子跑两次 `runMatch`，校验码和事件日志完全相同
  - ✅ 逐秒 `step` 到结束（中途不断取快照）与直接 `runMatch` 结果完全相同
  - ✅ 60 场不同对阵，每场都有 3 条关键原因，每条原因引用的事件都真实存在

**你可以自己看一眼**
- 在项目文件夹的终端里输入：`npm run sim -- --one --seed 42`
- 你会看到：一场"潮声俱乐部 vs 烬羽电竞"的中文战报、选手评分、经济差和关键事件。
