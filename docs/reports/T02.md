# T02 汇报：地图与移动

**结论**：✅ 完成。小人能在节点图上按最短路走，兵团沿各自的兵路行进。

**做了什么**
- `src/sim/map.ts`：把地图数据变成可查询的图，预先算好任意两点的最短路（全图只有 25 个节点）。
- 位置用"在哪条连线上、走了百分之几"来表示，画面层可以换算成坐标做平滑移动。
- 支持追一个正站在连线中间的目标（以后抓人、追击要用）。
- `src/sim/units.ts`：兵团生成，沿自己的兵路走，不会抄近道穿野区。
- 调试脚本：`npx tsx tools/path-debug.ts B_BASE R_BASE 40`，打印路线、每个节点的距离和耗时。

**怎么验证的**
- `npm test`：通过 34 / 失败 0（本任务新增 12 个）
- `npm run lint`：0 个问题
- 验收逐条：
  - ✅ 地图连通，任意两节点都有路径，路径长度和距离表一致
  - ✅ 地图沿河道镜像对称，蓝红双方到各自塔的距离完全相等（保证公平）
  - ✅ 同样的输入，移动结果逐位一致
  - ✅ 三路兵团（双方）都在预计秒数经过路中点

**地图示意**（坐标 0–1000，蓝方左下、红方右上；▲蓝塔 △红塔 ◆中立资源 ·野区）

```
 R_TOP_T1(380,90)  R_TOP_T2(640,90)  R_BASE(910,90)
TOP_MID(100,100) ── △ ──────── △ ──────── 【红基地】
   │  ◆守望者(300,300)                 △ R_MID_T2(740,260) 
   ▲ B_TOP_T1(90,380)   ·红野区        △ R_BOT_T2(910,360)
   │      ·蓝野区    MID_MID(500,500)   │
   ▲ B_TOP_T2(90,640)       ◆晶核(700,700)  △ R_BOT_T1(910,620)
   │    ▲ B_MID_T1(390,610)              │
【蓝基地】(90,910) ── ▲ ──────── ▲ ──── BOT_MID(900,900)
          B_BOT_T2(360,910)  B_BOT_T1(620,910)
```

- 三条兵路：每路"蓝基地 → 蓝二塔 → 蓝一塔 → 路中点 → 红一塔 → 红二塔 → 红基地"。
- 双方野区各 3 个点：上野区、下野区、靠基地的"野区核心"。
- 两个中立资源点在河道上：上河道"守望者"、下河道"晶核"。
- 行走耗时（移动速度 40）：蓝基地走中路到红基地 29 秒，走上路/下路约 41 秒。
