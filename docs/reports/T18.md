# T18 汇报：界面升级

**结论**：✅ 完成。P1 的新玩法都有了界面，手机竖屏能用。

**做了什么**
- **顶部日历条**：日期、阶段、"还有几天比赛"。可以开始/暂停、选 1× / 2× / 4×，也可以直接"⏭ 下一场"。
  - 时间按天自动走，1× 每天约 2 秒。
  - 到比赛日会自动停下并进入比赛。有人报价、合同快到期、资金偏低、赛季结束时也会停下提示。
- **收件箱**：所有消息按时间排，有未读红点。AI 的报价可以直接点"接受/拒绝"；合同到期、财务、比赛消息有按钮直达对应页面。
- **训练页**：选本周训练侧重（6 种，写清了练什么、累多少、花多少钱），看全队的疲劳、士气、状态、成长空间。有人太累会提示休息。
- **合同转会页**：
  - 我的合同：谁哪年到期、身价多少。到期的人直接在这里谈续约：选年限、接受开价、还价一次，或不续约。
  - 别人的报价：接受或拒绝。
  - 转会市场：其他俱乐部的选手，休赛期可以报价买人。
- **财务页**：
  - 每周收支拆开显示：工资、赞助、联赛分成、周边、训练费。
  - 声望和能签哪档赞助；赞助商列表，可以直接签约。
  - 未来 4 周现金流预测；资金偏低时给出具体的挽救办法。
- **历史页**：每个赛季的冠军、你的排名、季后赛成绩、赛季末资金，以及每季的完整积分榜。
- **选手卡**：点任何选手的名字都能打开，看能力、疲劳、士气、合同、身价、生涯战绩、英雄熟练度和能力变化曲线。
- **赛程页**：加了季后赛对阵；积分榜前 4 名带 ★。
- **主页**：新增"待处理"清单，比如未读消息、有人报价、合同到期、没签赞助、选手太累、转会窗口开放，每条都有按钮直达。
- **手机竖屏**：导航横向滑动，表格在手机上只显示关键列，按钮加大方便点。
