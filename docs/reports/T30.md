# T30 汇报：负责人市场与雇佣

**结论**：✅ 完成。现在可以雇经理、教练、财务，能解雇、能续约，每周付工资；办公室里多了一张长桌，雇了谁就有谁坐着办公。负责人**还不会动手干活**（下一步 T31），现在只花钱，界面上写明了这一点。

**做了什么**
- **候选人**：每个休赛期每个岗位 3 个候选人，开新档时也有一批。
  - 每人 3 项能力（识人 / 带队 / 理财）。本职那项最高，比如财务的理财最高，另外两项都比本职低。
  - 每人一种风格：保守 / 激进 / 重青训。
  - 周薪按本职能力算（400 起，每高 1 分加 30，取整到 50），签约费 = 4 周工资。
  - 合同 2 个赛季。
  - 候选人用单独的随机数，按存档种子和赛季生成，不会影响比赛和赛季里的其他随机结果。
- **退役选手当教练**：刚退役、巅峰能力 75 以上的选手，每季最强的 1 人会成为教练候选。他的带队能力按以前的意识和配合算，收件箱会收到"××想当教练"。
- **雇佣**：付签约费，岗位填上，权限默认"小事自己办"。一个岗位只能有一个人，要换先解雇。
- **解雇**：付剩余合同工资的一半，岗位回到"亲自管"。
- **续约**：合同最后一个赛季可以续 2 季，再付一次签约费，工资不变。不续约的话，合同到期时他会离开，收件箱有消息。
- **工资**：每周一结算时多一项"负责人工资"，财务窗口和签人时的"每周预计净收支"都算进去了。
- **界面**：
  - 菜单里多了"负责人"，点办公室前面的长桌也能打开。
  - 每个岗位一张卡片：有人时显示头像、能力条、风格、工资、合同、三档权限按钮和"解雇 / 续约"；空缺时显示候选人和"聘请"。
  - 顶部能设单笔额度（1 万 / 3 万 / 5 万 / 10 万）和核心保护人数（0–5）。
- **基地**：办公室前面放了一张长桌，三台笔记本。雇了几个人就坐几个人在敲键盘。原来那个位置的盆栽挪走了。
