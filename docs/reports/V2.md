# V2 汇报：英雄和选手的像素形象

**结论**：✅ 完成。比赛里的小方块换成了 10 个各不相同的 Q 版像素英雄：会走路、挥武器、放技能时举起武器发光，阵亡会倒在地上。比赛结果和以前完全一样。

**做了什么**
- **10 个英雄各有一套造型**，衣服是所在战队的颜色，一眼能分清两边：

  | 英雄 | 造型 |
  |---|---|
  | 磐岳（坦克） | 铜盔、红缨，方盾 + 大锤 |
  | 铁棘（坦克） | 尖刺铁盔，刺盾 + 狼牙锤 |
  | 夜枭（刺客） | 猫头鹰耳兜帽、蒙面，短匕 |
  | 绯刃（刺客） | 红色马尾、白头带，双刀 |
  | 星烛（法师） | 星星尖帽、长袍，星杖 |
  | 霜笛（法师） | 冰蓝长发、冰晶发卡，寒笛 |
  | 逐风（射手） | 羽毛绿帽，长弓 |
  | 赤隼（射手） | 刺头 + 护目镜，连弩 |
  | 青萝（辅助） | 叶冠绿发、长袍，藤杖 |
  | 鸣钟（辅助） | 斗笠、长袍，铜铃杖 |

- **每个英雄 6 个动作**：
  - 站立
  - 走路两帧，走的时候身体一上一下
  - 攻击：武器向前挥或拉弓
  - 放技能：举起武器，顶端发光
  - 倒地
- **比赛画面里**：
  - 移动时朝着走的方向；打架时转身朝着目标，武器一下一下挥。
  - 放技能时举杖发光；被晕时头上转小星星，身体发蓝。
  - 阵亡后躺在原地，约 2 秒后淡出，复活后在基地重新出现。
  - 脚下有战队颜色的圈。前后站的人会按远近遮挡。
  - 普攻连线从胸口发出，不再从脚底。
- **阵容窗口**里选好英雄后，会显示这个英雄的像素形象、称号和技能。
- **选手卡**左上角加了这名选手的像素头像，和他在基地里的小人长得一样。

**做了哪些决定**（已记入 DECISIONS.md，D45）
- 造型用文字网格画，和基地小人同一套做法。每个英雄有自己的头饰、脸、身体类型（轻装 / 重甲 / 长袍）和武器；衣服用战队颜色。以后数据里加了新英雄、还没画造型时，先借用同类型英雄的样子。
- 动作只看比赛画面收到的数据，不碰比赛本身，所以看比赛和跳过的结果仍然完全一样（原有测试继续保证）。
- 英雄放大 2 倍画，保持像素清晰。比赛画面原来的大小和地图不变（地图是 V3 的事）。

**需要你知道的**
- 跑测试时发现，两赛季浏览器测试偶尔卡住，原因在测试脚本本身：
  1. 打完总决赛，"赛季结束"窗口会自动弹出，而且只弹一次。
  2. 测试脚本有时刚好在它弹出时执行"关掉所有窗口"，把它也关了。
  3. 之后脚本找不到"进入下一赛季"按钮，就卡住了。

  已修：赛季打完时，如果这个窗口已经被关掉，脚本就从"菜单 → 概况"里找同一个按钮。游戏本身没问题，玩家关掉以后也能从概况进入下一赛季。
