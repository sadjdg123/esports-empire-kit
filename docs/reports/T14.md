# T14 汇报：训练与成长、状态

**结论**：✅ 完成。选手会成长、会累、有情绪，而且这些都会影响比赛。

**做了什么**
- **每周训练**：全队选一个侧重：操作 / 意识 / 配合 / 心态 / 英雄熟练度 / 休息。每周一结算。
- **成长**：侧重的那项长得最快，其他三项也会涨一点。越年轻长得越快，27 岁后基本停住，30 岁以后不管怎么练都会慢慢下滑。每个人有隐藏的潜力上限，快到上限时成长放慢直到停止。上场比赛也会长经验，用哪个英雄，哪个英雄就更熟练。
- **疲劳**：每场比赛 +18，训练周 +10，休息周 −35，每天自然恢复 2。超过 50 以后比赛发挥开始下降。
- **士气**：赢球 +4，输球 −5，坐板凳 −3，每天慢慢回到 60。士气高的人状态（form）会往上走，士气低的往下走。
- 选手的生涯统计（场次、胜场、击杀/死亡/助攻）开始记录。
- AI 俱乐部先用简单规则训练：累了就休息，不累就轮流练各项。完整的 AI 经营在 T17。
- 所有数值都在 `growth.json`，疲劳对比赛的影响在 `match.json`，记入 D32。

**怎么验证的**
- `npm test`：通过 109 / 失败 0（本任务新增 8 个）
- `npm run lint`：0 个问题；`npm run build`：成功
- 平衡测试：G1–G8 全过，结果和 T13 之前一模一样（平衡测试里的选手疲劳都是 0）。G9（速度）这次没过，见下方。
- 验收逐条：
  - ✅ 高潜力年轻选手一个赛季平均成长明显高于老将。实测一个赛季下来，20 岁及以下平均 +4.3，21–24 岁 +2.7，25–27 岁 +1.0（四项能力平均值）。30 岁以上的人一个赛季约 −2。
  - ✅ 连续不休息的队伍胜率下降：从不休息的队伍到赛季后段疲劳约 90，和状态满的同一支队伍对打，胜率约 20%；每三周休息一次，疲劳一直在 30 以下。
  - ⚠️ G1–G8 通过；G9 这台机器上没过：1000 场 66 秒，标准 ≤60 秒。
    - 原因是机器变慢了，不是 T14 的改动。会话中途容器重启过一次，换到了一台更慢的机器。
    - 同一台机器上，前后背靠背各跑一次：改动前的旧代码 63 秒，改动后 66–67 秒。单线程速度两边一样（104–117 毫秒/场，波动比差距还大）。之前测出的 57 秒是在原来那台机器上。
    - 比赛引擎这次只加了一个乘法，每场比赛开头算一次，不在每秒的循环里。
