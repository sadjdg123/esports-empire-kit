# V4 汇报：比赛表现与走位（只改画面）

**结论**：✅ 完成。比赛看起来更像真的在打：小人不再叠成一团，打团时两边各站一侧、近战在前远程在后；普攻有箭矢和法球，10 个技能各有特效；挨打闪白、飘伤害数字；阵亡冒小幽灵，复活有光柱；打团时镜头自动拉近。比赛结果和以前完全一样。

**做了什么**
- **站位**（只是画的位置，比赛里的真实位置不变）：
  - 同一个地方的几个人会散开，排成一排，名字不再叠在一起。
  - 两队碰上时，各自往自己那边退一点：近战站前排，远程往后站。
  - 没遇到敌人时，远程跟在近战后面走。
  - 位置是平滑移过去的，不会一下跳过去；画的位置离真实位置最多 60（地图宽 1000）。
- **普攻**：
  - 射手射箭（逐风是长箭，赤隼是弩箭）。
  - 法师和辅助扔一颗自己颜色的法球。
  - 近战挥出一道刀光。
  - 防御塔打出火球。
  - 命中时有小火花。
- **10 个技能各有样子**：
  - 磐岳：砸地冲击波加飞石
  - 铁棘：转动的荆棘护圈
  - 夜枭：紫色残影冲刺加一刀
  - 绯刃：三连斩
  - 星烛：流星从天而降、落地爆开
  - 霜笛：冰环加雪花
  - 逐风：一道穿云光箭
  - 赤隼：三连弩
  - 青萝：花叶升起的治疗圈
  - 鸣钟：头顶摇响的金钟加声波圈
- **受击**：
  - 被打中会闪一下白光。打团时人一直在挨打，所以同一个人最多 0.35 秒闪一次，而且伤害至少占血量 2% 才闪，不会一直白成一片。
  - 头上飘伤害数字（像素字体）：普通伤害白色，大伤害（一次掉两成血以上）黄色加大，治疗绿色。
  - 数字每 0.3 秒合并一次，避免满屏小数字；回血太少（不到 5%）不显示，比如慢慢自然回血。
- **阵亡和复活**：倒地时冒一圈烟，飘出一个小幽灵；复活时在基地亮起一道战队颜色的光柱。
- **镜头**：
  - 打团时自动拉近到 1.6 倍，跟着打架的人走；打完慢慢退回全图。
  - 比赛下方新增按钮"🎥 跟随团战 / 🗺 看全图"，随时切换。

**做了哪些决定**（已记入 DECISIONS.md，D47）
- 站位只是画法。比赛里英雄在路线的节点之间走，打架时常常站在同一点上，画面把他们分开，但不告诉比赛。真要让比赛里会站位、拉扯、绕后，是 V5。
- 镜头默认跟随团战。地面是画布的背景（V3），所以镜头动时背景跟着一起缩放和移动；不动时不额外耗电。
