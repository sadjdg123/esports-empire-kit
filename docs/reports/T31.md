# T31 汇报：决策与授权

**结论**：✅ 完成。负责人现在真的在干活：经理签人、续约、回应报价，教练排训练、排首发、选战术，财务签赞助、救急、升级设施。每个决定都写进日志，说清做了什么、为什么、花了多少钱，之后补上结果。能力高低在批量模拟里看得出来。
**要你知道的一件事**：全交给负责人打，目前比"认真的自动经营"弱一截（胜率约 30%，自动经营约 40%）。这是 T34 平衡要解决的，现在先如实记下。

**做了什么**
- **经理**（看"识人"）
  - 缺哪个位置就补哪个位置，复用 F2 的缺位判断，不会再出现"两个辅助没射手"。
  - 对每个选手有自己固定的看法：识人越低看得越偏，而且一直偏，不会每周变卦。
  - 风格：保守看性价比；激进只看能力；重青训偏爱 21 岁以下、潜力高的。
  - 工资上限 = 每周收入扣掉负责人工资后的五分之一，再乘风格系数（保守 0.9、激进 1.2、重青训 1.0）。
  - 续约：留队里最值得留的 6 人，要价超出工资上限或会吃掉备用金就不续；人数不够 5 人时放宽。
  - 人不够 5 个、钱又不够时，按游戏的应急规则签便宜的人，保证能上场。
  - 报价高于身价 1.25 倍才卖，否则拒绝。
  - 季前如果有明显更好的人（至少强 5 分）且不动备用金，就换掉最弱的首发。
- **教练**（看"带队"）
  - 每周一排训练：全队平均疲劳到 40 就休息，否则练全队最弱的一项。带队低的有时该休息不休息。
  - 比赛日排首发、选战术。对手惯用"稳健运营"时用"团战推进"克制（平衡报告里 58% 胜率，唯一明显的克制），其他情况用最稳的"团战推进"。带队低的有时看不准，沿用原来的打法。
- **财务**（看"理财"）
  - 没赞助就签最划算的一家。理财低的有时挑第二好的。
  - 钱是负数时才考虑应急赞助，而且只有"马上到账的钱 > 本季剩下几周少拿的赞助"才签。
  - 季前、队伍齐了，才拿备用金以外余钱的一半升级设施。备用金：保守 12 周开销、激进 4 周、重青训 8 周。理财低的有时把余钱全花了。
- **三档权限**
  - 亲自管：只出建议，写进日志，同一条建议一周只出一次。
  - 小事自己办：单笔超过额度的进待办（批准按钮是 T32 的活）。
  - 全权托管：自己做主，但"首发最强 N 人"有人出价时一律交给你。
- **界面**：负责人窗口里每个岗位下面多了"最近的决定"（已办 / 建议 / 待批），带原因和结果。删掉了 T30 留的"还不会干活"那句话。
- **负责人工资调低了**：原来三个人一周 6000 多，接近球队一半收入，托管的俱乐部全都欠债。现在周薪 = 200 + (本职 − 30) × 12，最贵的一周约 1000 元。

**怎么验证的**
- `npm test`：253 个全部通过，新增 10 个：
  - 经理：全权时补齐 5 个位置并写原因；亲自管只出建议、什么都不动、不重复；小事自己办额度内直接做，超了进待办、不重复，批准后能执行；核心选手全权托管也不卖。
  - 教练：疲劳时休息、不累时练最弱项；带队 10 分的教练比 100 分的明显更常犯错；比赛日排出合法首发。
  - 财务：没赞助会签；队伍不齐不升设施。
  - 全托管打完一整季；同一个种子两次结果完全相同（日志、资金一模一样）；赛季结束补上签约结果。
- `npm run lint`：0 个问题；`npm run build`：成功。
- 40 场固定对局校验码不变。没雇人时游戏和以前完全一样。
- 浏览器测试：基地点物件和两个赛季手机测试都通过，没有报错。
- 批量模拟（16 个种子 × 3 个赛季，三个岗位全权托管）：

| | 胜率 | 3 季后平均资金 | 最少的一局 | 犯错次数 |
|---|---|---|---|---|
| 好负责人（能力 90） | 29.8% | 10.9 万 | 4.4 万 | 8 |
| 差负责人（能力 20） | 24.1% | 9.2 万 | 2.6 万 | 80 |
| 普通自动经营（不雇人） | 39.9% | 15.2 万 | 10.3 万 | — |

  - 没有一局破产或凑不齐人。
  - 和自动经营的差距：钱少一部分是负责人工资（每季 2–4 万）；胜率差 10 个百分点，主要在经理签人偏保守和教练训练安排上。T34 平衡时处理。
