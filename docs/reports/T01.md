# T01 汇报：核心类型、随机数、示例数据

**结论**：✅ 完成。后续所有任务共用的"地基"已就位，接口冻结。

**做了什么**
- `src/core/types.ts`：技术规范第 4 节的全部类型，外加数据文件、画面快照（RenderSnapshot）的类型。
- `src/core/rng.ts`：自写的种子随机数（sfc32 算法），支持 `fork`（派生互不干扰的子随机流）和 `state`（存档用）。
- `src/core/config.ts`：读取并校验全部 JSON，错误会精确到"哪个文件第几项哪个字段"；另有阵容合法性检查 `validateLineup`。
- 数据：10 个英雄、30 名自由选手、5 支 AI 俱乐部、经济与比赛参数。

**怎么验证的**
- `npm test`：通过 22 / 失败 0
- `npm run lint`：0 个问题
- 验收逐条：
  - ✅ 同一种子生成 1 万个数完全一致
  - ✅ `fork` 不影响父随机流，兄弟流之间互不影响
  - ✅ 缺字段 / 类型错 / 超范围 / 重复 ID / 俱乐部缺位置 / 未知英雄 / 地图连到不存在的节点，都能报出具体位置，例如 `players.json[3].attrs: expected an object`
