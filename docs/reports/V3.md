# V3 汇报：对战地图重绘

**结论**：✅ 完成。原来深绿底加几条粗线的地图，换成了开罗风的像素地图：草地、河流、石板路、木桥、林间小道、树林和岩石；防御塔、基地、守望者、晶核、野怪、小兵都换成了像素造型。比赛结果和以前完全一样，画面还比 V2 更流畅。

**做了什么**
- **地面**（整张图，比赛开始时画一次）：
  - 草地带深浅变化和小花。
  - 河流从左上流到右下，有浪纹和沙岸。
  - 三条路是石板路，跨河的地方是木桥：中路正中一座，左上、右下拐角各一座。
  - 野区之间是泥土小道，野怪营地是空地。
  - 基地前有石砖广场；守望者和晶核各有一座河中石台。
  - 没人走的地方长满树、灌木和岩石，地图外圈是一圈树林。
  - 树木和岩石都避开了所有道路、营地和建筑。
- **建筑和中立单位**（像素造型）：
  - 防御塔：石塔、战队颜色的尖顶和旗子；被推掉后变成碎石堆。
  - 基地：带两座小塔的城堡，顶上飘着战队颜色的水晶；被拆掉后变成废墟。
  - 守望者：石头巨像，眼睛发蓝光；被拿下后石台空着，等它重生。
  - 晶核：石座上浮着一颗紫色水晶，会上下轻轻飘；被拿下后只剩石座。
  - 野怪：紫色毛球怪，核心营地是更大的长角怪；被打死后消失，重生后再出现。
  - 小兵：每波 3 个小人，战队颜色，走路有动作；一波掉血后，站着的人会变少。
- **血条**：建筑和野怪只在掉血后才显示血条，画面更干净。
- **攻击连线**：防御塔的攻击从塔窗口射出。英雄打野怪时也有连线了（以前画面不知道野怪在哪）。

**做了哪些决定**（已记入 DECISIONS.md，D46）
- 地面一个像素和英雄造型的一个像素一样大（都放大 2 倍），所以整张图的像素颗粒统一。
- 树、石头、花的位置用固定的伪随机算出来，每场比赛都一样，不会闪。这只在画面里用，比赛模拟仍然只用种子随机数。
- 小兵在比赛里是"一波"一个单位，画成 3 个小人，人数跟着这波的血量减少。
- 建筑和野怪只在掉血后显示血条。

**需要你拍板的**：无

**风险和遗留问题**
- 英雄站在塔下时会挡住塔身，只露出塔底，这是故意的：人在前、塔在后。如果你觉得塔看不清，可以改成塔半透明。
- 守望者和晶核开局要过一会儿才刷出来，在那之前石台是空的。
- 手机竖屏时整张地图缩得比较小。V4 会加镜头跟随和打团拉近。
