# T33 汇报：集团报表

**结论**：✅ 完成。菜单里多了"报表"，有三个标签：本周、本赛季、决策日志。钱去哪了、负责人干得怎么样，一屏能看清，手机上不用横着划。

**做了什么**
- **本周**
  - 这一周的收入、支出分项（赞助、联赛分成、奖金、选手工资、负责人工资……），还有合计和净收支。
  - 右上角可以切到本赛季以前的任意一周。
  - 下面是三个负责人这一周各做了什么。
- **本赛季**
  - 战绩、资金从多少变成多少、全季收支分项。
  - 每个负责人一张业绩卡：办了几件、你批了几件、建议、驳回、过期各几条，经手花了多少钱。
  - 经理：本季签下的每个人，签来以后打了几场、赢了几场，离队的会标出来。
  - 教练：排过几场战术、赢了几场（胜率）、安排休息几周。
  - 财务：本季最低资金、资金为负的有几周。
- **决策日志**
  - 能按负责人筛、按类型筛（签人、续约、训练、战术、赞助……，只显示出现过的类型）。
  - 点一条展开，看为什么、花了多少钱、结果、谁做的、第几周。
  - 训练、赞助这类不会有"结果"的，就不显示结果那一行。
- **入口**：菜单"报表"；负责人窗口顶部也有"看报表和决策日志"按钮。
- 收件箱筛选里补上了"负责人"一类（T32 漏了）。

**怎么验证的**
- `npm test`：263 个全部通过，新增 4 个：
  - 分项加起来等于账本合计。
  - 整个赛季：赛季开始的钱 + 净收支 = 现在的钱；每周净收支加起来 = 全季净收支；每条决定都落在正确的那一周、正确的负责人下面，一条不漏。
  - 业绩：经理签人的数量和日志一致，签来的人场数、胜场不超过球队的场数；经理经手花费和日志一致；教练赢的场数不超过排的场数；财务的最低资金不高于赛季开始和现在。
  - 没雇人时报表也能正常显示。
- `npm run lint`：0 个问题；`npm run build`：成功。
- 40 场固定对局校验码不变。
- 浏览器测试：基地点物件和两个赛季手机测试都通过，没有报错。报表三个标签在手机宽度上都没有横向滚动。

**做了哪些决定**（D65）

- "签来以后的成绩" = 现在的生涯场数减去签约时的生涯场数。
