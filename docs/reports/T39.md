# T39 汇报：分部界面与比赛画面

**结论**：✅ 完成。菜单里多了"集团"，能开分部、进分部窗口管人排阵，还能看射击和卡牌的对局回放。手机竖屏上都点过一遍，没有报错，没有横向滚动。

**做了什么**
- **集团**（菜单"集团"）：
  - 最上面是全集团的声望、资金、每周固定收支。
  - MOBA、射击、卡牌各一张卡片：本季战绩、名次、每周收支、谁在管、下一场是周几。
  - 没开的分部显示开办条件和"开办"按钮，条件不够时写明差什么。
  - 人数凑不齐时用红字提醒会判负。
- **分部窗口**，5 个标签：
  - 概况：每周收支明细、奖金说明、本周训练、积分榜、历届成绩。
  - 选手：我的队伍（续约、解约）和自由市场（射击可以按位置筛）。每人显示年龄、能力、位置或拿手卡组、各项能力、状态好坏。
  - 阵容：射击是五个位置各选一人，再选打法，不是本职的位置会标出来；卡牌是三台各选人和卡组，能看到每种卡组的熟练度。都有"一键推荐"。
  - 比赛：最近一场的回放，加最近 12 场的结果和原因。
  - 总监：候选人、聘请、解雇、"我亲自管 / 交给总监"，还有总监做过的事和原因。
- **射击回放**：每个回合一个小方块（绿赢红输），点哪个看哪个。能"重放这一回合"：一条条出击倒、下包、拆包，倒下的人名字变灰，A / B 点位高亮；随时"直接看结果"。下面是全场数据表和战报原因。
- **卡牌回放**：每一局一个小方块。重放时两条血条随回合变化，每回合写打了多少伤害、回了多少血，失误、读牌、组合技、斩杀会标出来。下面是各台比分和战报原因。
- 分部比赛的结果和换季消息，点助理气泡的"去看看"会打开集团窗口。
