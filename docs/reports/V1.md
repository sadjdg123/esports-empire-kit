# V1 汇报：基地即主界面（开罗风）

**结论**：✅ 完成。打开游戏就是你的俱乐部大楼，所有功能都从楼里的东西或右下角"菜单"进入，不再有网页标签栏。手机竖屏一屏放得下。

**做了什么**
- **整栋楼占满屏幕**，楼是剖开的两层，像开罗游戏那样：
  - 楼下训练室：8 张电竞桌、白板、饮水机、绿植、俱乐部大海报、彩旗、LED 屏。
  - 楼上左边休息室：沙发、两张床、电视、自动售货机。
  - 楼上右边办公室：书架、奖杯柜（拿过冠军会摆金杯，亚军摆银杯）、保险柜、办公桌，桌后坐着你（经理）。
  - 门口院子：信箱、告示牌、树。屋顶有俱乐部名字的招牌。
- **楼里的东西都能点**，点了打开对应窗口：
  - 白板→阵容，电脑桌→训练，信箱→收件箱，告示牌→签人，办公桌→合同转会
  - 电视→赛程，书架→战报，奖杯柜→历史，保险柜→财务
  - 点小人→选手卡
- **东西上会冒提醒**：有事要处理时，对应的东西头上跳"！"。比如有未读消息时信箱跳，阵容没排好时白板跳，合同快到期时办公桌跳，没有赞助商时保险柜跳；有人很累时电脑桌冒汗。
- **顶部状态条**：日期、几天后比赛、资金、声望，开始/暂停、1×/2×/4×、下一场。
- **右下角"菜单"**：一格一格的像素图标，包括概况、收件箱、阵容、训练、签人、合同转会、赛程、财务、战报、历史、设置。
- **所有页面改成开罗风弹窗**：米黄底、橙色标题栏、木框、粗按钮。窗口开着时时间自动停。
- **人物对话**：第一次进游戏，助理"小禾"会教你哪里能点。之后收件箱的新消息由相关选手或助理用"头像＋一句话"说出来，可以点"去看看"或"知道了"。
- **小人会动**：
  - 平时在楼下训练；休息周或太累就坐电梯上楼睡觉或躺沙发；状态差就站着发呆；合同快到期就去办公室。
  - 赢了比赛当天会在原地欢呼跳。
- **比赛日**弹出"比赛日"窗口：对手是谁、阵容好没好，点"开始比赛 ▶"进比赛画面，或者点"调整阵容"。
- **赛季结束**自动弹出"赛季结束"窗口：排名、季后赛成绩、资金变化、"进入第 N 赛季"。
