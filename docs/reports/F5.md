# F5 汇报：检查 Gemini 的三批改动（F3、F4、V7），修两个真问题

**结论**：⚠️ 三批改动大体没问题，比赛结果和数值一点没变。但 V7 带进来两个真问题，已经修好：
1. **点基地里的家具打不开窗口**（手机、电脑都是）。
2. **手机上助理对话框的"知道了"被底部快捷栏挡住**，提示关不掉。

**检查了什么**
- `npm test`：293 个测试全部通过；`npm run lint`：0 个问题；`npm run build`：成功。
- 40 场固定对局校验码不变。
- 新旧代码各跑一遍"MOBA + 射击 + 卡牌连打两个赛季"，钱、战绩、选手、随机数状态完全一样。说明 F4 声称"不改数值"属实。
- 逐行看了游戏逻辑的改动（合同、负责人、训练、存档字段）：都只是多记录、多显示信息。
  - 新的"还价最低能接受"提示，和真实谈判规则用的是同一个公式，不会误导你。
  - 新加的"上周训练成果"是可选字段，旧存档照常能读。
- 测试有两处改动：
  - 合同测试换成用新提示的底线去还价，仍然检查"按这个价能谈成"，没有放松。
  - 性格平衡测试的局数从 200 减到 80，对比基准改成固定的 50%。结论没变，但这条测试比以前粗一点（每次误差约 ±6%，标准是 ±15%），可以接受。
- 浏览器测试：原有 4 套里有 2 套失败，一查就是下面两个问题。V7 的汇报里只跑了快速测试，没跑浏览器测试。

**修了什么**
1. **点家具打不开窗口**
   - 原因：V7 加了"按住拖动基地"。按下时整块画面会"抓住"这次操作，松手后浏览器把点击发给了外层画面，家具本身收不到。Gemini 的测试只算了家具坐标对不对，没有在浏览器里真点。
   - 改法：松手时如果没拖动，就当成一次点击，按位置找家具。
   - 现在点基地能打开 12 个窗口（比以前多了屋顶招牌→集团），点小人能打开选手卡。拖动画面照常能平移，拖动时不会误开窗口。
2. **"知道了"被快捷栏挡住**
   - 原因：手机上快捷栏变成两行（约 93 像素高），对话框却按 62 像素固定摆放。
   - 改法：对话框按快捷栏实际高度浮在它上面；文字太长就在框里滚动。另外手机上基地画面贴着顶部放，去掉了顶部一大块空白。

**验证**
- 293 个测试全部通过；4 套浏览器回归（基地点物件、两个赛季、完整一季手机和电脑）全部通过；电脑离线包照常能玩。

- `src/ui/App.tsx`（量快捷栏高度）
