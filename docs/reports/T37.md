# T37 汇报：卡牌比赛引擎

**结论**：✅ 完成。卡牌分部的比赛规则"牌局"写好了，纯逻辑、没有画面，和 MOBA、射击引擎都独立。批量模拟证明：卡组克制、选手能力、卡组熟练度都影响结果，但都不是绝对的。

**规则**（原创，数值都在 `src/data/card.json`）
- 团体赛：每队 3 人，按出场顺序一对一。每台三局两胜，先赢 2 台的队赢。
- 每局双方各 20 点生命，轮流出牌，把对面打到 0 就赢。后手多 2 点生命，抵消先手优势。上一局输的人下一局先手。
- 4 种卡组，节奏不一样：
  - 快攻：前几回合伤害高，越拖越没劲。
  - 中速：每回合都稳，没有明显克制和被克制。
  - 控制：前期弱，后期每回合回血、伤害越来越高。
  - 组合技：平时伤害低，第 6 回合起有机会一套带走，对面读牌好可以拦下来。
- 克制是一个圈：快攻克组合技，组合技克控制，控制克快攻。
- 选手 4 项能力：计算（少失误）、读牌（挡下对面一半伤害、拦组合技）、运营（后期更强）、心态（落后时不掉线）。每个人对每种卡组还有熟练度。
- 每局还有"手气"：这一局牌好还是牌差，所以强的人也会输。
- 赛后有战报：比分、三条关键原因（卡组克制、熟练度差距、读牌、对面失误、组合技、让一追二）、全场最佳。

**怎么验证的**（批量模拟，每项 2000 场）

| 检查 | 结果 | 我定的标准 |
|---|---|---|
| 同种子重跑 | 完全一致 | 一致 |
| 两队完全一样，蓝方胜率 | 48.6% | 45%–55% |
| 先手的人单局胜率 | 50.8% | 45%–55% |
| 平均能力高 15 分 | 85.4% | 65%–88% |
| 平均能力高 5 分 | 65.2% | 有优势但不稳赢 |
| 卡组熟练度 90 对 40 | 79.3% | 明显占优 |
| 单局卡组克制 | 快攻打组合技 58%，组合技打控制 63%，控制打快攻 61%；中速对谁都在 47–53% | 有克制，没有通吃 |
| 一局多少回合 | 平均 7.5 | 6–10 |

- `npm test`：新增 5 个测试（同种子一致、比赛结构合法、双方和先后手均衡、强者和熟练者赢得多、克制成圈且没有万能卡组），全部通过。
- 这个引擎调得比较久。一开始卡组强弱完全一边倒（0% 对 100%），因为每回合的数字太确定，差 1 点伤害就决定胜负。加了"每局手气"之后才变成有来有回，克制关系改用单独的系数控制。
- 注意：整队三个人都带同一种卡组时，克制会被放大到 70% 以上（三台都被克）。实际排阵是每人各带各的，这正是排阵要动脑子的地方。
