## 我看到的问题（试玩时可以留意）
1. **雇满 3 个好负责人一季大约 1.4 万**，攒钱会比自己管慢。值不值，你试了说。
2. **待批的事目前不多**：小事自己办、额度 3 万时，一季大概一两件。可能太少，也可能刚好。
3. **教练的"失误"不太显眼**：只在训练和战术上，要去日志里才看得到。
4. GATE-4 留下的设施划不划算、性格和默契存在感弱，还没有结论。
