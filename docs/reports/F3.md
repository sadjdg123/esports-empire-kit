# 汇报 · F3 界面与画面细节修正及测试提速

## 1. 结论
✅ 已完成。把之前截图里暴露出来的 5 处界面/画面遮挡与错位问题全部修好，给基地屋顶加上了“集团分部”招牌入口和缺人提醒，同时把自动测试运行时间缩短了约 30 秒，比赛模拟结果与原版 100% 一致。

## 2. 做了什么
1. **顶部提示条不再挡按钮**：把黄色提示条（比如“回放倍速 2x”“已设为练习操作”）挪到了屏幕最顶端（距离顶部 8 像素），变紧凑，不再盖住弹窗第一排的切换按钮。
2. **手机上 6 个标签按钮不再换行变形**：把弹窗顶部的标签栏改成单行自动均分宽度，在 390 像素宽的手机屏幕上，“‹ 集团 / 概况 / 选手 / 阵容 / 比赛 / 总监”6 个按钮稳稳排成一行，不会再把“总监”挤到第二行拉成大长条。
3. **MOBA 比赛画面文字防重叠**：
   - 两个英雄贴在一起打架时，头顶的“等级+名字”标签会自动左右错开或上下叠放，不再糊成一团。
   - 同一地点同时发生多个事件（比如“团战！”和“击杀 某某”同时冒出）时，飘字会自动分层错开，而且起点上移，不再盖住地图上的“晶核”“守望者”名字。
4. **基地大楼细节修复与分部联动**：
   - 修复了一楼左侧“战术白板”冒泡提醒位置太高、戳进二楼床铺的问题，现在感叹号稳稳停在白板上方。
   - 微调了一楼两排训练电脑桌的前后间距，看着更舒展。
   - 屋顶招牌现在可以直接点击打开“集团”窗口；当你开了射击或卡牌分部后，屋顶招牌两侧会自动挂出对应分部的小铭牌；如果分部还没签够人，屋顶招牌上还会冒出感叹号提醒你。
5. **测试提速**：精简了“比赛性格胜率平衡测试”里的重复模拟场次（利用红蓝交替天然的 50% 基准，单文件从 45 秒降到约 14 秒），并新增了 `npm run test:fast` 快速自测命令。

## 3. 门哥怎么验
1. 在项目文件夹打开终端，输入 `npm run dev`，用浏览器打开显示的地址。
2. **看基地屋顶招牌**：直接点大楼屋顶写着俱乐部名字的木牌，会直接打开“集团”窗口；如果开了射击或卡牌分部且没签满人，屋顶木牌上会有跳动的红色感叹号，两侧还会挂出分部小铭牌。
3. **看分部窗口标签栏**：打开“集团”进入任意分部，顶部的“‹ 集团 / 概况 / 选手 / 阵容 / 比赛 / 总监”6 个按钮在手机宽度下排成整齐的一行；点回放里的“1x/2x/4x”切换倍速时，顶部弹出的提示条不会挡住这排按钮。
4. **看 MOBA 比赛画面**：打一场正式比赛，观察中路团战时英雄头顶的名字以及“团战！”“击杀”飘字，文字之间清楚错开、不再互相压字。
