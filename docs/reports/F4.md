# 汇报 · F4 经营体验与报表反馈升级

## 1. 结论
✅ 已完成。把原本藏在后台的四大经营反馈（每周训练涨了多少、负责人为什么提这个审批、选手为什么开这个续约价、阶段目标还差多少）全部用大白话展示在界面上，不改任何比赛结果和数值平衡。

## 2. 做了什么
1. **每周训练成长战报**（`src/game/training.ts`、`src/ui/pages/Training.tsx`、`src/ui/pages/Home.tsx`）
   - 每周一发薪与训练结算后，自动记录本周训练成果（`lastTraining`）：练了什么项目、谁进步最快、全队默契涨了多少、哪些英雄熟练度提高了、休息周恢复了多少疲劳。
   - 在“训练”窗口新增“上周训练成果”卡片，并在下方队员状况表增加“上周”列，每个人的能力涨跌或疲劳恢复一目了然；“总览”窗口也同步显示最新一周的训练摘要。
2. **负责人决策理由与待办审批透明化**（`src/game/delegation.ts`、`src/ui/pages/Staff.tsx`、`src/ui/pages/Reports.tsx`）
   - 在“负责人 -> 待你拍板”里，每条待批事项现在会写清楚：
     - **为什么找你批**（是因为要卖受保护的核心主力、还是要动用安全备用金、还是超过了单笔授权额度）。
     - **关联详情**（涉及选手的年龄/能力/潜力/周薪，或升级房间带来的具体加成）。
     - **批准后的资金变化**（比如 `批准后资金：¥120,000 → ¥85,000`）。
   - 在“报表 -> 本周 / 决策日志”里，直接把每条决定的原因展示在条目下方，不用再一条条点开才能看原因。
3. **合同续约谈判参考提示**（`src/game/contracts.ts`、`src/ui/pages/Contracts.tsx`）
   - 在“合同转会”窗口和到期选手谈续约时，直接列出他的**要价构成**（能力对应的公允周薪、是否有“爱钱/务实”性格、当前士气高低、行政室减免比例）。
   - 给出**还价提示**（按当前士气最低大约能接受多少周薪），并把还价输入框默认值直接设在这个合理底线上，不再让你盲猜还价线。
4. **阶段目标进度条与近期目标高亮**（`src/ui/pages/Goals.tsx`、`src/ui/styles.css`）
   - 在“目标”窗口顶部新增“🎯 离达成最近”提示框，直接标出当前完成度最高、最容易先拿到的下一个目标和奖励。
   - 新增“全部 / 进行中 / 已达成”筛选按钮，并把原来的窄进度条换成了醒目的全宽渐变进度条（同时显示 `当前值 / 目标值` 和百分比）。

## 3. 门哥怎么验
1. 终端运行 `npm run dev`，打开浏览器。
2. **看每周训练成果**：推进过一个周一后，点基地一楼电脑打开“训练”窗口，可以看到新增的“上周训练成果”卡片，以及表格里的“上周”涨跌列。
3. **看负责人审批与日志**：在“负责人”窗口聘请经理或财务，把单笔额度调小（如 ¥10,000），推进到周一触发“待你拍板”，可以看到新增的“触发原因”“选手/房间详情”和“批准后资金”；点“看报表和决策日志”可以直接看到每条决定的原因。
4. **看续约提示**：当队里有本季合同到期的选手时，打开“合同转会”，在续约栏可以看到“要价构成”和“还价提示（最低大约能接受 ¥XXX）”。
5. **看阶段目标**：打开菜单里的“目标”，顶部会高亮离达成最近的目标，每个未完成目标都有全宽渐变进度条和百分比。
