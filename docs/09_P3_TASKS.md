## T29 数据扩展与存档 v4

**目标**：P3 要用的数据先就位，旧存档能升级。
**范围**：`src/core/types.ts`、`src/data/*.json`（新增 `staff.json`）、`src/game/state.ts`、`src/save/*`、`tests/*`。
**要做的事**
1. 负责人：编号、名字、岗位、3 项能力（0–100）、风格、周薪、合同、来历（市场 / 退役选手）。
2. 俱乐部：每个岗位的负责人（可以空着）、权限档位、额度、核心选手保护名单。
3. 游戏：待办队列、决策日志（只保留最近若干条，数量放配置）。
4. `staff.json`：岗位说明、候选人生成规则、能力对决策的影响系数、周薪区间，都是〔待确认〕。
5. 存档 v4：v3→v4 自动升级，升级后所有岗位"亲自管"，玩法和以前完全一样。
**验收**：P2 存档读进来能接着玩；新字段有校验；比赛校验码不变。

## T30 负责人市场与雇佣

**目标**：能找人、雇人、换人。
**范围**：`src/game/staff.ts`、`src/ui/*`、`src/render/club/*`（只加办公位和小人）、`tests/*`。
**要做的事**
1. 每个休赛期刷新一批候选人。退役选手中能力强的，有机会成为教练候选（带队能力和他的意识、配合挂钩）。
2. 雇佣要付签约费和周薪，可以解雇（付违约金）。
3. 负责人卡：能力、风格、周薪、履历，一句话写清"他擅长什么"。
4. 基地：楼里多出 3 个办公位，有人上任就有小人坐着办公。点他打开负责人卡和权限设置。
**验收**：雇佣和解雇的钱入账正确；候选人按种子固定；手机上能完成雇人。

## T31 决策与授权

**目标**：负责人真的在替你干活，而且能看出好坏。
**范围**：`src/game/staff.ts`、`src/game/strategy.ts`（复用现有自动经营逻辑）、`tests/*`。
**要做的事**
1. 经理：补位签人（不会漏位置，复用 F2 的判断）、续约、回应报价、买人。识人能力决定看人准不准，风格决定偏向老将还是新秀。
2. 教练：每周训练安排、阵容、战术。带队能力决定选得对不对，比如该休息时会不会休息、战术克制看不看得准。
3. 财务：赞助、设施升级、留多少备用金。理财能力决定会不会乱花钱。
4. 三档权限：
   - 亲自管：只在收件箱给建议。
   - 小事自己办：额度内直接做，超出的生成待办（T32）。
   - 全权托管：全部自己做，但遵守"核心选手不卖"和预算上限。
5. 每个决定写日志：做了什么、为什么、资金影响，之后补上结果（比如"签下 X，周薪 Y；本季 8 场 6 胜"）。
6. 所有决定都用存档里的随机数，同一种子结果相同。
**验收**：每个岗位、每档权限都有测试；额度和核心选手保护有测试；能力高低的差别能在批量模拟里看出来。

## T32 待办与审批

**目标**：该你拍板的事不漏，也不烦。
**范围**：`src/game/staff.ts`、`src/game/season.ts`（只接线）、`src/ui/*`、`tests/*`。
**要做的事**
1. 待办窗口：每条写清"谁提的、要做什么、为什么、花多少钱"，有"批准 / 驳回"。
2. 批准后由负责人执行，驳回或过期就记进日志。过期时间〔待确认〕默认 2 周。
3. 只有"卖核心选手、超预算"这两种会暂停时间，其余只在顶部显示待办数。
4. 每周一收件箱一条汇总："本周负责人做了 N 件事，待你批 M 件"。
**验收**：批准、驳回、过期都有测试；暂停只在大事时发生；手机上一只手能批完。

## T33 集团报表

**目标**：一眼看出钱去哪了、谁干得好。
**范围**：`src/game/report-staff.ts`（新）、`src/ui/*`、`tests/*`。
**要做的事**
1. 周报：本周收入和支出分项，每个负责人做了哪些事。
2. 赛季报：全季收支、成绩、每个负责人的业绩。比如经理签的人打了多少场、贡献多少胜；财务的备用金管得怎么样。
3. 决策日志窗口：按负责人、按类型筛选，每条能点开看原因和结果。
4. 手机竖屏排版，表格太宽时只显示关键几列（参照 T27 历史窗口的做法）。
**验收**：报表数字和账本一致（有测试）；截图检查手机排版。

## T34 P3 平衡与 20 赛季验收

**目标**：委任好玩、可控，不是一个按钮自动赢。
**要做的事**
1. 20 个赛季 × 16 局：全托管（好 / 一般 / 差负责人），对比"普通经营"的自动玩法。要求：
   - 好负责人的成绩接近普通经营，不能明显更好
   - 差负责人会犯错，但俱乐部不会一路破产
   - 托管下资金中位数不超过开局 3 倍，首发能力 66–72，冠军分布健康
2. 负责人的周薪和能力要算得过来：好负责人贵，但值。
3. G1–G9 全过。试玩指南 v4。
**验收**：上面每条都有报告数字；不过的按规则调，调 3 轮还不过就停下交门哥。
