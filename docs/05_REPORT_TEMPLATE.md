# 任务汇报模板

每完成一个任务（或卡住时），按下面格式用简体中文汇报给门哥。先结论，少术语。

---

## Txx 汇报：任务名称

**结论**：✅ 完成 / ⚠️ 部分完成 / ❌ 卡住（一句话说明）

**做了什么**（3–6 条大白话）
- …

**怎么验证的**
- `npm test`：实际运行结果（通过 x / 失败 y）
- `npm run lint`：实际运行结果
- 该任务验收标准逐条：✅ / ❌ + 一句说明

**你可以自己看一眼**（如果这个任务有能看到的东西）
- 在项目文件夹的终端里输入：`……`
- 你会看到：……

**改了哪些文件**
- 新增：…
- 修改：…
- 有没有动范围外的文件：没有 / 有（说明原因）

**做了哪些决定**（已记入 DECISIONS.md）
- …

**需要你拍板的**（没有就写"无"）
- 问题：…
  - 选项 1：… 代价：…
  - 选项 2：… 代价：…
  - 我推荐：… 原因：…

**风险和遗留问题**
- …

**下一步**：Txx（等你回复"继续"）

---

## 卡住时的汇报（替代上面的"做了什么"）

- **现象**：…
- **试过的办法**（至少 3 次）：…
- **我判断的原因**：…（注明是确定还是推测）
- **可选方案**：
  - 修：… 代价…
  - 换：… 代价…
  - 绕开：… 代价…
- **我推荐**：…
