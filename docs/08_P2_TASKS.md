# P2 开发任务书：经营纵深

> 2026-10-23 · 门哥让我"先往下做"后编写（GATE-3 试玩问题延后，见 D49）· 依据 GDD 第 15 节 P2
> 目标：可以连续经营很多个赛季，每个赛季都有新的取舍；**没有明显的经济爆炸，也没有一招鲜的最优打法**。
> 原则不变：一次一个任务、每个任务有测试和汇报、关卡停下等门哥。P2 不做 P3 内容（负责人、预算授权、集团报表）。

## T21 数据扩展与存档 v3

**目标**：P2 需要的数据先就位，旧存档能升级。
**范围**：`src/core/types.ts`、`src/data/*.json`、`src/game/state.ts`、`src/save/*`、`tests/*`。
**要做的事**
1. 选手：性格列表、成长类型（早熟 / 正常 / 大器晚成）、生涯记录（每季的球队、场次、冠军、MVP）、是否退役。
2. 俱乐部：设施等级（5 个房间）；默契表（选手两两之间 0–100）。
3. 游戏：名人堂列表；历届 MVP。
4. 新配置文件：`facilities.json`、`traits.json`。
5. 存档 v3 + v2→v3 升级：老选手随机补性格和成长类型（用存档里的种子，结果固定），设施从 1 级开始，默契从 0 开始。
**不做**：任何新玩法效果。
**验收**：全部旧测试通过；P1 存档升级后能继续打完赛季；新字段都有校验。

## T22 设施（房间升级）

**目标**：给钱找到去处，让"先升级哪间房"成为每个赛季的取舍；画面上看得到俱乐部在变好。
**范围**：`src/game/facilities.ts`、`src/data/facilities.json`、`src/render/club/*`、`src/ui/*`、`tests/*`。
**要做的事**
1. 5 个房间，各 1–3 级〔待确认的数值都进配置〕：
   - 训练室：训练成长 +10% / +20%
   - 休息室：每天疲劳恢复 +1 / +2
   - 办公室：续约要价 −5% / −10%，赞助档位要求降低
   - 分析室（新房间）：英雄熟练度成长 +25% / +50%
   - 直播间（新房间）：周边收入 +15% / +30%
2. 升级花钱，时间在休赛期最好；每级每周维护费。AI 俱乐部也会按预算升级。
3. 基地画面：每级有不同的家具，两间新房间放进楼里。点房间弹出升级窗口：现在几级、下一级的效果、价格。
**不做**：自由摆放家具（见 Q6 备选）。
**验收**：加成都有单元测试；20 个赛季里普通经营的钱不再一路涨（中位数控制在开局的 3 倍以内）；手机上 5 间房都能点开。

## T23 职业生涯与退役

**目标**：选手有起有落，联赛长期保持水平，老将退役、新秀接班。
**范围**：`src/game/training.ts`、`src/game/talent.ts`、`src/game/career.ts`、`src/data/growth.json`、`src/data/ai.json`、`tests/*`。
**要做的事**
1. 三种成长曲线：早熟（巅峰早、下滑早）、正常、大器晚成（巅峰晚）。
2. 退役：29–34 岁，每个赛季末按年龄和下滑程度判断；玩家队里的人退役前一个月发消息。
3. 重新校准新秀（能力和潜力上限）：20 个赛季里首发平均能力保持在 66–72 之间。
**验收**：20 赛季报告里首发平均能力不再一路下降；每赛季有退役、有新秀；同一个种子结果相同。

## T24 性格

**目标**：选手不只是数字，签人时多一层考虑。
**范围**：`src/data/traits.json`、`src/game/*`、`src/sim/units.ts`（只读性格，换算成系数）、`src/ui/*`、`tests/*`。
**要做的事**
1. 约 8 种性格，每人 0–2 个，数值都进配置〔待确认〕。比如：
   - 大心脏：落后时发挥更好
   - 玻璃心：落后时更容易失误
   - 刻苦：训练成长 +20%
   - 懒散：训练成长 −20%
   - 领袖：全队士气回升更快
   - 独行侠：操作 +，配合 −
   - 务实：续约要价低
   - 爱钱：续约要价高
2. 选手卡、市场列表显示性格和一句话说明。
**验收**：每种性格的效果有单元测试；带性格和不带性格的同一支队，胜率差在设定范围内（Q7）；G1–G9 仍通过。

## T25 默契

**目标**：频繁换人有代价，固定阵容有回报。
**范围**：`src/game/chemistry.ts`、`src/sim/units.ts`（只读）、`src/ui/*`、`tests/*`。
**要做的事**
1. 两两默契 0–100：一起首发打一场 +、练"配合"那周 +；赛季间不在一起会下降。
2. 首发 5 人的平均默契，小幅影响集合速度和集火（上限按 Q7）。
3. 阵容窗口显示默契，签人时提示"新人默契为 0"。
**验收**：默契效果有单元测试；20 个赛季里"每季大换血"和"固定阵容"两种经营都打得下去，没有一种明显碾压。

## T26 英雄池扩充

**目标**：阵容选择更多，克制关系更丰富。
**范围**：`src/data/heroes.json`、`src/render/pixel/heroArt.ts`、`src/render/matchFx.ts`、`tests/*`、平衡报告。
**要做的事**
1. 新增 6 个原创英雄（名字、技能都原创，不用现有游戏的），每个有像素形象和技能特效。
2. 选手的英雄熟练度扩到新英雄（老选手对新英雄从低熟练度开始）。
3. 重跑 G1–G9，并检查单个英雄胜率不过高（在 45%–55% 之外的要调）。
**验收**：G1–G9 全过；16 个英雄都有人用；画面里每个都能分清。

## T27 赞助目标与名人堂

**目标**：赛季有阶段目标，长期经营有记录可看。
**范围**：`src/game/finance.ts`、`src/data/economy.json`、`src/ui/pages/History.tsx`、`tests/*`。
**要做的事**
1. 赞助加目标：如"进季后赛额外奖金""排名前 2 再奖"，签约时能看到。
2. 历史窗口：历届冠军和 MVP；选手生涯（每季球队、场次、冠军）；名人堂（拿过多冠或长期主力的退役选手）。
**验收**：目标奖金入账有测试；名人堂规则有测试；手机上历史窗口好看。

## T28 P2 平衡与 20 赛季验收

**目标**：确认 P2 的东西放在一起长期运行不失控。
**要做的事**
1. 20 个赛季 × 8 局报告：钱（普通经营中位数不超过开局 3 倍）、人才（首发平均 66–72）、冠军分布（至少 3 家、没人拿超过 60%）。
2. 没有一招鲜：战术（G4）、训练安排、设施升级顺序、性格搭配，各自比较，没有哪个选法在所有情况下都明显最好。
3. G1–G9 全过；试玩指南 v3。
**验收**：上面每条都有报告数字；不过的按规则调，调 3 轮还不过就停下交门哥。
