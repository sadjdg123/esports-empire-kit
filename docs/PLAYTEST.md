# P0 试玩指南

## 怎么打开

**手机或电脑，直接点这个链接**：https://claude.ai/artifact/8LEgrkkf9fhDm8gEcK3Byt
（只有你本人能打开。手机横屏看比赛更清楚。）

想在自己电脑上跑（需要先装 Node.js）：在项目文件夹的终端里依次输入 `npm install`、`npm run build`、`npm run preview`，再用浏览器打开终端里显示的地址（一般是 `http://localhost:4173/`）。

## 一局怎么玩（约 15–40 分钟，看你看不看比赛）

1. **开局**：起个俱乐部名、选队伍颜色，点"成立俱乐部"。
2. **市场**：签 5–8 名选手，上单、打野、中单、射手、辅助至少各一人。看两样东西：顶部资金条（还能撑几周），和右侧"还缺哪个位置"。
3. **阵容**：点"一键推荐"或者自己选；挑一种战术，点"保存阵容"。
4. **主页**：点"进入下一周"，先扣工资、发赞助，再进入比赛。
5. **比赛**：可以暂停、1×/2×/4× 倍速、跳过。跳过和看完的结果一模一样。
6. **战报**：看结论、3 条关键原因、经济曲线、评分和奖金。然后回主页打下一轮。
7. 打满 10 轮，主页会显示最终排名和资金变化。想重来：设置 → 开始新游戏。

**存档**：每一步都会自动存在这个浏览器里。换手机或换浏览器前，到"设置 → 复制存档文本"，把那段文字存进备忘录；换设备后在"粘贴存档文本导入"粘回去即可。

## 建议你试的几种玩法（每种打一个赛季，或者打几轮看感觉）

| 试法 | 怎么做 | 想验证什么 |
|---|---|---|
| 省钱流 | 市场按"性价比"排序，每个位置签最便宜的 | 钱是不是越打越多，但排名垫底 |
| 豪门流 | 每个位置签能力最高的 | 是不是很能赢，但钱会亏光 |
| 战术对比 | 同一套人，前 5 轮用一种战术，后 5 轮换另一种 | 战报里能不能看出战术的作用 |
| 故意排错位置 | 让辅助去打上单，射手去打野 | 是不是明显变弱，战报有没有指出来 |
| 英雄不熟 | 给选手换一个熟练度很低的英雄 | 技能效果差不差，战报会不会提到 |

## 试完请回答这 5 个问题（一句话就行）

1. 比赛看得懂吗？
2. 能感觉到自己的选择影响结果吗？
3. 2–3 分钟一场，长还是短？
4. 最想加什么？
5. 最烦什么？
