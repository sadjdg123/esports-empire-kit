# P1 试玩指南（GATE-3）

## 怎么打开

**手机或电脑，直接点这个链接**：https://claude.ai/artifact/8LEgrkkf9fhDm8gEcK3Byt
（只有你本人能打开，地址和 P0 一样。手机竖屏就能玩，看比赛时横屏更清楚。）

**旧存档**：你之前 P0 的存档会自动升级成新版本，可以接着玩。想从头体验完整赛季，建议到"设置 → 开始新游戏"。

想在自己电脑上跑（需要先装 Node.js）：在项目文件夹的终端里依次输入 `npm install`、`npm run build`、`npm run preview`，再用浏览器打开终端里显示的地址（一般是 `http://localhost:4173/`）。

## 一个赛季怎么走（约 30–60 分钟，看你看不看比赛）

一个赛季 = **休赛期 2 周 → 常规赛 10 轮（每周六一场）→ 季后赛（前 4 名：半决赛 + 总决赛）→ 颁奖 → 下一个赛季**。

1. **开局**：起名、选颜色，点"成立俱乐部"。
2. **休赛期（转会窗口开着）**：
   - **市场**：签 5–8 人，每个位置至少一人。右上角可以选合同签几年（1–3 年）。
   - **合同转会**：可以向别的俱乐部报价买人。别人也会来报价买你的人，报价在收件箱里。
   - **财务**：选一家赞助商（声望越高，能签的越好）。不选的话，开赛时系统替你签一家。
   - **阵容**：一键推荐，或者自己排，选战术，保存。
   - **训练**：选本周练什么。练得越多越累，隔几周练一次"休息"。
3. **让时间走**：顶部日历条点"▶ 开始"，时间一天天走，可以选 1×/2×/4×。也可以点"⏭ 下一场"直接跳到比赛日。
   - 每周一发工资、收赞助，结算一周训练。
   - 比赛日会自动停下进入比赛。有人报价、合同快到期、钱不够时也会停下提醒你。
4. **比赛**：暂停、倍速、跳过都行，跳过和看完结果一样。看完进战报。
5. **合同到期**：合同最后一个赛季，到"合同转会"里谈续约：接受开价、还价一次，或者放手。不续约的人赛季结束后离队。
6. **季后赛**：常规赛前 4 名进季后赛，一局定胜负。
7. **赛季结束**：主页显示排名、季后赛成绩、资金变化。点"进入第 2 赛季"继续：选手都长一岁，新秀会进入市场。
8. **随时看**：
   - 主页"俱乐部基地"：小人在训练室练、在休息室躺、发呆或去办公室谈合同。点小人看详情。
   - 主页"待处理"清单：该做的事都列在这里。
   - "历史"：往届冠军和你的成绩。

**存档**：每一步都会自动存在这个浏览器里。换手机或换浏览器前，到"设置 → 复制存档文本"，把那段文字存进备忘录；换设备后在"粘贴存档文本导入"粘回去即可。

## 建议你试的几种玩法

| 试法 | 怎么做 | 想验证什么 |
|---|---|---|
| 正常经营 | 每个位置签中等价位的人，正常训练、隔几周休息 | 一个赛季下来钱大致持平，排名中游 |
| 豪门流 | 一开始就签最贵的 | 能不能赢，钱会亏多少，第二季能不能缓过来 |
| 从不休息 | 训练一直练操作 | 赛季后半段是不是明显打不动了 |
| 培养新秀 | 签几个 16–18 岁"成长空间很大"的人 | 一两个赛季后是不是真的变强了 |
| 买卖选手 | 休赛期从 AI 那里买人，或者把人卖给 AI | 价格合不合理，AI 的反应像不像真的俱乐部 |

## 试完请回答这几个问题（一句话就行）

1. 一个完整赛季（含季后赛）玩下来，节奏是快还是慢？
2. 时间自动走（▶ 开始）和直接跳到下一场，你更常用哪个？
3. 钱的压力合适吗？太紧、太松，还是刚好？
4. 训练、疲劳、合同、转会，哪个有意思，哪个嫌麻烦？
5. 手机上有没有哪里难点、看不清、找不到？
6. 最想加什么？最烦什么？
