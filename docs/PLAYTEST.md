# P2 试玩指南 v3（GATE-4）

## 怎么打开

**手机或电脑，直接点这个链接**：https://claude.ai/artifact/8LEgrkkf9fhDm8gEcK3Byt
（只有你本人能打开，地址一直没变。手机竖屏就能玩，看比赛时横屏更清楚。）

**旧存档**：P0、P1 的存档会自动升级，可以接着玩。P2 的很多东西要打几个赛季才看得到（退役、名人堂），想完整体验，建议到"设置 → 开始新游戏"。

想在自己电脑上跑（需要先装 Node.js）：在项目文件夹的终端里依次输入 `npm install`、`npm run build`、`npm run preview`，再用浏览器打开终端里显示的地址（一般是 `http://localhost:4173/`）。

## 一个赛季怎么走（约 30–60 分钟，看你看不看比赛）

一个赛季 = **休赛期 2 周 → 常规赛 10 轮（每周六一场）→ 季后赛（前 4 名）→ 颁奖 → 下一个赛季**。

1. **开局**：起名、选颜色，点"成立俱乐部"。整个游戏都在俱乐部大楼里：
   - 楼里的东西都能点：白板→阵容，电脑桌→训练，信箱→收件箱，告示牌→签人，楼上办公桌→合同转会，电视→赛程，书架→战报，奖杯柜→历史，保险柜→财务，院子里的红色工具箱→设施，小人→选手卡。
   - 右下角"菜单"里也能找到所有功能。
   - 哪件东西头上跳"！"或"♪"，就是那里有事。
2. **休赛期**：
   - **签人**：签 5–8 人。名字下面的彩色标签是**性格**：绿色好、红色坏、黄色有好有坏，点标签看说明。
   - **合同转会**：买卖选手。
   - **财务**：选赞助商。每家都写着**赛季目标**（比如"进季后赛 +¥8,000"），赛季结束时达成就发奖金。
   - **设施**：点工具箱，花钱把 5 个房间升到 2、3 级。每升一级楼里的样子会变，之后每周要付维护费。
   - **阵容**：一键推荐，或者自己排。最上面有**首发默契**条：一起打得越久越高，换人会掉。
   - **训练**：默认"自动安排"，累了自动休息。也可以自己选练什么。
3. **让时间走**：顶部"▶ 开始"让时间一天天走（1×/2×/4×），或者"⏭ 下一场"直接跳到比赛日。
4. **比赛**：比赛日弹窗里点"开始比赛 ▶"看比赛，或者点"直接看结果 ⏭"，两种结果一样。英雄现在有 16 个。
5. **合同、退役**：
   - 合同最后一个赛季可以谈续约。
   - 29 岁以上的选手可能退役。你的人要退役时，赛季结束前 4 周会收到消息。他会打完这个赛季，新赛季开始时离开。
6. **赛季结束**：
   - 评出本季 **MVP**，赞助目标结算。
   - 新赛季开始时，退役名单和新秀一起出来。
7. **随时看**：
   - **历史**（奖杯柜）：历届冠军、MVP，还有**名人堂**。作为主力拿过 3 个冠军、当过 MVP，或者当了 10 个赛季主力的退役选手会进去。
   - **选手卡**：性格、成长类型（早熟 / 正常 / 大器晚成）、每个赛季的职业生涯。

**存档**：每一步都会自动存在这个浏览器里。换设备前到"设置 → 复制存档文本"，存进备忘录；换设备后"粘贴存档文本导入"。

## 建议你试的几种玩法

| 试法 | 怎么做 | 想验证什么 |
|---|---|---|
| 长期经营 | 连打 5 个以上赛季 | 老将退役、新秀接班，联赛会不会越打越弱或越打越强 |
| 固定阵容 vs 大换血 | 一局一直用同一批人，另一局每季换人 | 默契的好处和换人的代价，感觉得到吗 |
| 升级设施 | 有钱就升设施 vs 一直不升 | 值不值，维护费压不压人 |
| 挑性格 | 专挑"刻苦""领袖"，或者故意签"玻璃心" | 性格有没有存在感 |
| 换战术 | 同一批人，试试四种战术 | 打法差别看得出来吗 |
| 新英雄 | 培养新秀练新英雄（岩犀、墨鸦、炎纹、雷弦、泉音、铜卫） | 新英雄好不好用、好不好认 |

## 试完请回答这几个问题（一句话就行）

1. 连打几个赛季后，还有动力继续吗？最想看的是什么（冠军、名人堂、培养新秀、赚钱）？
2. 设施、性格、默契，哪个有意思，哪个感觉不到？
3. 钱的压力合适吗？太紧、太松，还是刚好？
4. 退役消息、MVP、名人堂，会让你在意某个选手吗？
5. 比赛里 16 个英雄能分清吗？四种战术看得出区别吗？
6. 手机上有没有哪里难点、看不清、找不到？
7. 最想加什么？最烦什么？
