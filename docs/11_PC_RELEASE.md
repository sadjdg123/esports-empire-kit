# 电脑版：离线包与 Steam 上架步骤

## 一、离线包（已经能用）

**是什么**：一个文件夹，里面有 `index.html`、`game.js`、`怎么玩.txt`。在电脑上双击 `index.html`，用 Chrome 或 Edge 打开就能玩，不用联网，不用装任何东西。

**怎么生成**（需要电脑上装了 Node.js）：
1. 在项目文件夹里打开终端。
2. 输入 `npm install`，回车，等它装完（只有第一次需要）。
3. 输入 `npm run pack`，回车。
4. 看到"离线版已生成"以后，项目里会多出 `release/esports-empire-offline/` 文件夹。把这个文件夹压缩成 zip，就可以拷到别的电脑或者发给别人。

**要知道的**：
- 存档存在那台电脑的那个浏览器里。换电脑或换浏览器前，先到游戏里"设置 → 复制存档文本"保存好。
- 清除浏览器数据会把存档一起清掉。
- 已经测过：从文件夹直接打开，能开局、签人、看 MOBA 比赛，关掉再开存档还在。

## 二、上 Steam（需要你本人操作，这一步我没有做，也不会代办）

上 Steam 要注册、交钱、提交审核，这些必须是你本人的账号和决定。下面是大致步骤，供你以后决定要不要做。以 Steam 官方后台当时的说明为准。

1. **注册 Steamworks 开发者账号**：需要实名、税务和收款信息。
2. **交上架费**：每个游戏一笔，交给 Steam（金额以官方页面为准）。
3. **把网页游戏包成桌面程序**：Steam 要的是能双击运行的程序，不是网页。常见做法是用 Electron 或 Tauri 把现在的离线包包一层。这一步我可以做，但需要在一台 Windows 电脑上打包和测试。
4. **准备商店页面**：游戏名、介绍、截图、宣传图、预告片、年龄分级问卷。
5. **提交审核**：商店页面和游戏本体分别审核，通过后才能设置发售日。
6. **可选的 Steam 功能**：成就（可以直接对应游戏里的 14 个阶段目标）、云存档。都要额外接入。

**上架前建议先定的事**：
- 游戏名"电竞帝国"和所有队名、人名、英雄名是否要查重、注册商标。
- 现在的美术是程序画的像素占位图，够不够商店页面用。
- 卖不卖钱、卖多少。

## 三、我的建议

先用网页版和离线包玩够、改够，确定值得卖，再走第二步。第 3 步（包成桌面程序）等你定了要上架再做，不然白做。
